# IFFI MEDIA — Reusable Clinic Demo

Generic sales showcase for clinics. Not associated with Mingalar Medical Center or any other actual facility.

- No real client reviews/ratings, phone/address or actual booking data.
- Photo panels use real editorial Unsplash image URLs. Some images require internet access.
- Booking form displays an **in-browser preview only** and neither transmits nor stores personal details. Configure a prospect-specific verified WhatsApp number, services, hours and privacy terms before offering live booking.
- Add a prospect's official logo and original approved clinic photography only with permission.
- Host as standalone static site: `index.html`, `styles.css`, `clinic-overrides.css`, `script.js`.
- Built by https://www.iffimedia.com. No fake results or price claims.
